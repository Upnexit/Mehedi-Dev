# 3D Developer Portfolio

আমি যেহেতু একজন full stack web developer, তো আমি একটি professional মানের আমার নিজের জন্য একটি portfolio website তৈরি করতে চাচ্ছি, যেখানে আমার সমস্ত project থাকবে। আমার যাবতীয় সমস্ত কিছু, একটা professional portfolio website, যেমন হয় mobile layout থেকে শুরু করে desktop layout, একদম সবকিছু professional level-এ থাকবে। যেহেতু আমি একজন developer, সেটি উপস্থাপন করার জন্য একটি professional আমার portfolio লাগবে। এবং আমি তোমাকে একটি image দিয়েছি, সেই image-টি তুমি আমার ব্যবহার করবে profile icon হিসেবে। যাবতীয় একটা portfolio-তে যা যা লাগে, তুমি একদম professionally একটা portfolio website তৈরি করে দাও। একদম three D animated website, অর্থাৎ scroll করলে যেমন three D একটি vibe আছে, এরকম একদম professional animated, আ, portfolio website চাচ্ছি।
